## 15:4x 轮（第 128 轮）— accelerate#4504 评审返工

- **评审返工的 A/B 基线陷阱**：返工分支上做 pre-fix 对照时，`git checkout <旧提交> -- src/...` 会把同分支上**未提交的返工**洗掉（本轮连续三次）——返工期 A/B 必须**先 commit 返工，再 checkout 基线**，恢复用 `git checkout HEAD --`。
- per-rank 状态文件的正确镜像对象是同文件的 RNG-state 模式（每 rank 直写 torch.save，绕过 save() 的主进程门控）。
- DDP 对称数据（两 rank 同 micro-batch）下局部梯度经同步恒等——per-rank 与单文件两种方案恰好同值，**发散场景需要按 rank 分片数据**；无法复现时在回复中如实说明 + 请评审人重跑其脚本（一个未决点）。
- quality_check 的 claims 逐字匹配对正文换行敏感——正文措辞含换行时用行内子串。
