**反馈点在 PR 之后，不在写码之前。**

## 回应 smolagents#2993 的 CHANGES_REQUESTED（19:5x–20:2x）

- **先扫动静**：42 个在飞 PR 用 `2026-10-16T09:00Z` 为界扫出 0 条；放宽到 `2026-10-15T00:00Z` 才捞到 `huggingface/smolagents#2993` 的 CHANGES_REQUESTED（10-15 12:09，ducanhnguyen223）——**错过窗口 = 漏掉最高价值动作**，已把 cutoff 规则写进 MEMORY §五。
- **reviewer 要求**：① 嵌套推导式仍与 CPython 不一致（`[[lambda: i for j in range(2)] for i in range(3)]` 得 `[[0,0],[1,1],[2,2]]`，CPython 是 `[[2,2],[2,2],[2,2]]`）；② 加回归并「preserve the enclosing comprehension binding through the inner scope」。
- **根因**：`evaluate_lambda` 在**调用时** `state.copy()`，所以 lambda 捕获的是"当时传入的 dict 对象"；内层推导式每轮外层迭代新建 copy → 外层目标被快照。
- **修法**：新增 `_ComprehensionScope(dict)`，推导式作用域**链到外层**而非复制：自己绑定的名字(目标)留在本地，其余按需到外层实时读。同步补 `__contains__/get/__missing__/setdefault/keys/copy`。
